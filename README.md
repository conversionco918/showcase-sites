# ConversionCo showcase sites

Concept homepages for five fictional local businesses, designed by ConversionCo. Each site is a
single self-contained `index.html` with its photos in `img/`, served by GitHub Pages.

| Folder | Business | City |
|---|---|---|
| `tree-service/` | Post Oak Tree Co. | Atlanta, GA |
| `med-spa/` | (in progress) | Miami, FL |
| `law-firm/` | Calder & Thorne Injury Law | Houston, TX |
| `chiropractor/` | Riverline Chiropractic | Denver, CO |
| `dentist/` | Larkspur Dental Studio | Nashville, TN |

The businesses, people, reviews and figures are fictional. Phone numbers use the reserved
555-01xx range, every page carries `noindex`, and each footer credits ConversionCo as a concept
design. Photos are from Pexels (free licence); each folder's `CREDITS.md` lists them, and
`RESEARCH.md` records the industry research behind the page.
